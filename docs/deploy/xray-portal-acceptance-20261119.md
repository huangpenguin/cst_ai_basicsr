冻结版本 `03eb5cc6515ce309a5c40410514e4c28` 已到 Cloud Ready。训练归档 46,120,960 字节，SHA256 `49a98fcba6c850f3ce406a352d8175cd6e1a8e971d747268a470aa56fbf084b8`，GCS generation `1795082465204829`。独立流式下载再次核对 SHA256、CRC32C 与大小；没有保存云端下载图像到 Git。现有训练数据预检确认 4 train / 1 monitor / 0 test，训练归档格式兼容。没有提交 Vertex 训练。

原 TIFF 的认证下载及哈希一致性通过；冻结后仍可只读查看 GT/LQ、映射、划分与审核备注。原件、截图、ZIP、TAR、数据库、ADC 和私有续传会话均不进入 Git。

## 断点与故障恢复

- **内网大文件**：纯合成条件 ZIP，21,474,990,690 字节（约 20 GiB），通过真实 HTTP/tus 传输。确认收到 64 MiB 后暂停；旧偏移重发返回 409；重启 tus 服务并创建新会话，以批次访问码恢复，确认偏移仍为 64 MiB。
- **完整性**：全部上传用时 549.639 秒，独立读取 NFS 原件核对 SHA256 后总用时 770.456 秒。此结果包含本次主机磁盘竞争和重启，不作为内网理论峰值带宽。没有整份文件缓存进应用内存；tusd 工作内存观察约 35 MiB，cgroup 峰值包含文件缓存，OOM/oom_kill 均为 0。
- **边界**：大文件测试只验证传输、恢复和 NFS 完整哈希，没有解包 20 GiB、进行配对或同步到云端；其状态仍要求校验和审核，普通上传会话调用同步接口返回 403。
- **真实 GCS 续传**：另用 25,190,400 字节的合成 TIFF 训练归档，在云端确认前 8 MiB 后模拟响应丢失；第二次同步查询原会话，偏移为 8,388,608，并从此继续。完成后的流式下载通过 SHA256、CRC32C、大小核对。该小型合成云对象保留作验收记录。
- **重启修复**：代理使用 Docker 动态 DNS，防止容器重启换 IP 后持续 502；挂载检查同时识别主机 NFS 源和 Docker 显示的精确 NFS 子目录源，不接受普通本地目录或任意同前缀来源。
